How to set one ↓

Set a reference device

  1. 1
    Pick the device you know. On Browse, press the target button on a card or table row . On a device sheet, press Set as reference.
  2. 2
    The list pins it on top and the list bar shows the pill Reference: Valve Steam Deck OLED. The pill stays while you filter, sort, or switch to cards.
  3. 3
    Read the deltas. Every other device gets a pill per value: ▲ 42% better than the reference, ▼ 18% worse, = 0% the same. Lower is better for price, weight and thickness. Higher is better for scores, screen, RAM and battery.
  4. 4
    In Compare, the reference column carries Reference. Press Set as ref on another column to switch. When the reference is not in the compare list, the first column acts as Baseline.
  5. 5
    Clear it with the × on the pill, or press the target again. The reference is separate from the compare list. Clearing the list keeps it.

Compare sizes at true scale

  1. 1
    Queue up to four devices. Tick the checkbox in the table, press Add to compare + on a card, or type a name in the header search.
  2. 2
    Open Compare. The size panel draws the outlines at 1 unit = 1 mm, overlaid or side by side. Views: front, back, top for thickness, and side. Clamshells are drawn open.
  3. 3
    Try the 3D tab. It stacks the outline to the stated thickness. Drag to rotate, or use the view presets.
  4. 4
    Read the grid. Every spec in one table. "Differences only" hides identical rows. The best value in each row is marked Best.

About the data

  • Every value has a source. On a device sheet, a dotted underline opens the link. Conflicts and unresolved fields are listed.
  • Weight is the measured figure where a reviewer weighed a unit, else the stated one. The sheet shows both.
  • Sizes describe the device as held: controllers on, battery pack on. A clamshell uses its closed footprint and is drawn open.
  • PassMark scores are per chip and mix TDPs and host devices. Treat them as a rough guide.
